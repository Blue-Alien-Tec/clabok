# Implementation Plans

One plan per scope, written when that scope enters planning. Naming:
`<scope-id>-<slug>.md`, for example `07-structure-and-book-settings.md`.

A plan is the resolved design record for one scope from
[../README.md](../README.md) §3. It answers the "Design decisions" section of the scope document,
breaks the work into tasks with a test and a verification step each, and states the resulting command
surface. It never changes a product statement from [../../PLAN.md](../../PLAN.md).

A plan is done when the scope's acceptance criteria are checkable from it and no design question of
the scope is left open.
